IF–THEN production rules guide the recommendation process.

RULE 01 · DIETARY MATCH

IF customer requires Vegetarian

AND restaurant offers Vegetarian food

THEN consider it a candidate

Filters restaurants according to customer dietary requirements.

RULE 02 · CUISINE MATCH

IF preferred cuisine matches

AND restaurant serves that cuisine

THEN increase match score

Uses preference matching to rank suitable restaurants.

RULE 03 · PREFERENCE LEARNING

IF customer likes a recommendation

THEN update preference weight

AND refine future ranking

Learns from customer feedback to improve future suggestions.
